# TECHFEST 2026 — Unleash the Impossible

Independent creative landing-page concept inspired by IIT Bombay Techfest. Not an official Techfest website. Event categories are illustrative; refer to https://techfest.org/ for authoritative dates, registration and event details.

## Tech stack
HTML5, CSS3, vanilla JavaScript. No 3D assets, no build process, no dependencies except optional Google Fonts (system fonts used as fallback).

## Features
Responsive layout, animated 2D hero artwork, mobile navigation, filterable event cards, scroll reveals, progress bar, animated counters, accessible reduced-motion fallback and official website CTA.

## Run
Open `index.html` in a browser. Keep `index.html`, `styles.css` and `script.js` together in the same folder.

## GitHub Pages
Upload all four files to the repository root, commit them, then go to Settings → Pages → Deploy from a branch → main → /(root) → Save. Wait for Actions to show a successful Pages deployment.

## Submission checklist
Include GitHub repository link, deployed live URL and demo recording link with Anyone with the link → Viewer access. If the portal has only one URL field, put all three in a public Google Doc and submit its link, provided the rules allow that format.
